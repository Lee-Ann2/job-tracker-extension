# Job Application Tracker

A browser extension with Python backend to track and automate job applications.

## Features
- Auto-track job applications from LinkedIn, Indeed, and Glassdoor
- Automatic application submission
- Excel-based tracking with color-coded status
- Statistics dashboard
- Status updates (Applied, Interview, Rejected, Ignored, Offer)
